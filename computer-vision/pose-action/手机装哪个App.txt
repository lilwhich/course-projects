【安卓手机】装这个
────────────────────────────────────────────
  名字：IP Webcam
  在哪：应用商店（华为/小米/OPPO/vivo 应用市场）搜「IP Webcam」
        找不到就去 Google Play 搜，或电脑上打开
        https://play.google.com/store/apps/details?id=com.pas.webcam
        下载后传到手机安装
  收费：免费（有广告，不影响画面）
  大小：约 32 MB

  装完怎么用：
    1. 打开 App
    2. 滑到页面最底部，点「Start server」
    3. 屏幕中间会出现一行地址，长这样：
           192.168.1.7:8080
       记下来（手机先别锁屏，App 界面别关）

  进 App 后建议改两项（在菜单里）：
    ・Video resolution（分辨率）→ 1280x720
      别用 1080p，宽带给不够会卡成幻灯片
    ・Video format → 保持默认（MJPEG），千万别改

  备用 App（万一 IP Webcam 广告太烦）：
    DroidCam → 装好后地址是 你的IP:4747


【苹果手机】装这个
────────────────────────────────────────────
  名字：IP Camera Lite
  在哪：App Store 搜「IP Camera Lite」（图标是摄像头的）
  收费：免费（有小水印，不影响识别）

  一定要看下面这段，苹果这个 App 多一步：
    IP Camera Lite 默认带账号密码，都是 admin。
    也就是电脑端要填的不是 192.168.1.7:8080，
    而是要带上账号密码：
           admin:admin@192.168.1.7:8080

  装完怎么用：
    1. 打开 App
    2. 点下面那个「Turn on IP Camera Server」
    3. 点底部的「Connect?」，里面列出 HTTP / RTSP / MJPEG 几行地址
    4. 抄 MJPEG 那一行的 IP 和端口（一般也是 8080）

  别装的：DroidCam（iOS 版要电脑端装客户端，还容易闪退）
          各类「手机当摄像头」直播软件（走的是云，不走局域网）


════════════════════════════════════════════════════════
  装完之后，三步连上
════════════════════════════════════════════════════════

▌第 1 步：连网络（这步最容易翻车，务必照做）

  ★ 最稳的办法：手机开热点，电脑连这个热点
    手机：设置 → 个人热点 → 打开
    电脑：右下角 WiFi 图标 → 连手机热点
    然后回手机 App 里点「Start server」

    为什么推荐这个：手机和电脑一定在同一个网段，
    不受路由器「AP 隔离」和校园网限制。
    电脑连热点后没外网也没关系，这套程序全离线跑。

  ⚠ 直接连同一个 WiFi 也能用，但校园网、公司网、
    访客网络经常开「AP 隔离」，两个设备互相看不见，
    表现就是扫描出来 0 个手机。

▌第 2 步：电脑上双击「⑦手机摄像头.bat」

  ・直接按回车 → 自动扫描（约 3 秒）
  ・或手填手机上的地址，安卓填 192.168.1.7:8080
                            苹果填 admin:admin@192.168.1.7:8080
  ・连上会显示「[成功] 已连接 + 分辨率」

  配置会存进 camera_source.txt，以后 ①②③④ 全部自动用手机，
  不用每次再填。想换回电脑自带摄像头：再跑一次 ⑦，输入 0。

▌第 3 步：双击「①机位自检.bat」，按说明书把手机摆好

  看到顶部变绿色「机位合格」才算过这一关。

  手机摆哪儿（这一步决定演示成不成）
════════════════════════════════════════════════════════

  ┌──────────────────────────────────────────────┐
  │ 摆法          │ 高度     │ 人站多远           │
  ├──────────────────────────────────────────────┤
  │ 放地上仰拍    │ 0 m      │ 2~3 米，镜头朝上   │
  │ 靠椅背/书架   │ 0.6~1 m  │ 2~2.5 米（推荐）   │
  │ 三脚架/夹桌边 │ 1~1.2 m  │ 2.5~3 米（最理想） │
  └──────────────────────────────────────────────┘

  笔记本自带的屏幕摄像头在屏幕上方，太高、视角太窄，
  只能拍到上半身——所以「站着」和「坐下」在数据上几乎一样，
  任何算法都分不出来。换成手机放低拍全身，才解决得了。

  ★ 一个必测的点：站着合格之后，一定要再坐下测一遍。
    坐下后人变矮，镜头不够低的话膝盖会掉出画面，
    那坐姿数据就废了，演示时坐下去不响应就是这个原因。


════════════════════════════════════════════════════════
  连不上时按顺序查这 6 条
════════════════════════════════════════════════════════

  1. 手机 App 里点「Start server」了没有？
     没点的话端口根本没开，扫描一定是 0 个。

  2. 手机是不是连的流量？电脑连的 WiFi？
     这俩不在一个网里，必须同一个网。

  3. 苹果手机上显示的是 127.0.0.1？
     那是手机自己，不能用。要用 192.168.x.x 这种局域网地址。

  4. 卡在「连接中」很久然后失败？
     大概率是「AP 隔离」，改手机开热点、电脑连热点。

  5. 第一次运行时 Windows 弹防火墙窗口是不是点了取消？
     必须选「专用网络」并允许。
     补救：控制面板 → Windows Defender 防火墙 →
           允许应用通过防火墙 → 找到 python.exe，勾上「专用」

  6. 想确认到底是程序问题还是网络问题：
     在文件夹里跑这条命令（会自己起一个假手机）：
         python _test_mjpeg.py --selftest
     输出「MJPEG 链路可用」= 程序没问题，问题在网络或手机上。

  三个实战提醒
════════════════════════════════════════════════════════

  ・手机插着电用。摄像头 + 屏幕 + WiFi 同时跑，半小时掉一半电。

  ・把手机自动锁屏关掉（设置 → 显示 → 休眠 → 永不）。
    录到一半屏幕灭了，App 被系统杀掉，流就断。

  ・无线有 0.2~0.5 秒延迟，你动作做完屏幕要慢半拍才反应。
    这是正常的，不是卡了，演示时提前跟老师说一句。
