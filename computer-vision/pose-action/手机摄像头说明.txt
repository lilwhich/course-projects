为什么值得折腾这一步
--------------------
笔记本屏幕摄像头装在屏幕上方，位置太高、视角太窄，
通常只拍得到你的上半身。而「站立」和「坐下」在骨骼上的
差别全在下半身——膝盖角度和髋部高度。

拍不到腿，这两类在数据上几乎完全一样，任何算法都分不出来。

手机可以随手放到地上、椅子边、书架下层，镜头朝上仰拍，
一拍就是全身。这是解决机位问题最省事的办法。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、手机端装什么（只需做一次）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▌Android：IP Webcam（完全免费，推荐）
  应用商店搜「IP Webcam」→ 安装 → 打开
  滑到页面最底部，点「Start server」
  屏幕上会出现一行地址，形如：
        192.168.1.7:8080
  记下它，之后要用。

  进入前建议在设置里改两项：
    · Video resolution → 1280x720（720p 最稳，1080p 吃带宽）
    · Video format → 保持默认（MJPEG）

▌iPhone：IP Camera Lite（免费，App Store 可搜到）
  App Store 搜「IP Camera Lite」→ 打开
  点「Turn on IP Camera Server」→ 点底部「Connect?」
  抄里面 MJPEG 那一行的 IP 和端口（一般 8080）

  ★ 苹果这个 App 默认带账号密码，都是 admin。
    所以电脑端填的地址要带上它们：
        admin:admin@192.168.1.7:8080
    （⑦向导会自动补成 http://admin:admin@...:8080/video）

  注意：iPhone 上很多同类 App 只给 RTSP 不给 MJPEG。
  如果 PC 端连不上，把 App 里 MJPEG 那一行的完整地址抄下来，
  直接在「⑦手机摄像头.bat」里手动填。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
二、网络怎么连（这一步最容易翻车）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

手机和电脑必须在同一个局域网里。

▌方案 A：手机开热点，电脑连手机热点  ★最可靠，推荐
  手机：设置 → 个人热点 → 打开
  电脑：连上这个热点
  然后在手机 App 里点「Start server」

  优点：一定同网段，不会有「AP 隔离」问题。
        不需要路由器，不受校园网限制。
  注意：电脑连热点后可能没有外网，但不影响使用——
        这套程序全离线跑。

▌方案 B：手机和电脑连同一个 WiFi
  能用，但有两个坑：
    · 校园网/公司网常开「AP 隔离」，设备之间互相看不见
    · 访客网络（Guest）也常常隔离
  如果扫描找不到手机，八成是这个原因，换方案 A。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、电脑端操作（一次性配置）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 双击 ⑦手机摄像头.bat
2. 直接回车 → 自动扫描局域网（约 3 秒）
   或者手动填手机上显示的地址，例如：192.168.1.7:8080
3. 连上后会显示：
       [成功] 已连接 http://192.168.1.7:8080/video
              分辨率 1280 × 720
4. 配置写入 camera_source.txt，**之后不用再填**

从这一刻起，①②③④ 全部自动用手机摄像头。
想改回电脑自带摄像头：再跑一次 ⑦，输入 0。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
四、手机摆哪里（决定成败）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

推荐三种摆法，从简单到讲究：

▌1. 直接放地上（最省事）
  手机平放或靠在墙上，镜头朝上仰 30~45 度。
  人站在 2~3 米外。
  缺点：有点俯视全身的感觉，但骨骼关键点照样能提。

▌2. 放在椅子上 / 书架下层（推荐）
  高度约 0.6~1 米，镜头略微上仰。
  人站在 2~2.5 米外。
  这是最接近正视角的摆法，特征最标准。

▌3. 用三脚架或夹在桌边
  高度 1~1.2 米，镜头水平。
  人站 2.5~3 米外。
  最理想，但不一定有器材。

摆好后双击 ①机位自检.bat 看结论：
  绿色「机位合格」→ 髋、膝、踝全部可见，可以开始采数据
  红色「看不到膝盖」→ 手机放低一点，或人再退远一点

★ 演示时一定要把「站着」和「坐下」的位置都测一遍。
  站着能看到脚踝，不代表坐下时也看得到——坐下后人体变矮，
  如果镜头不够低，膝盖会落到画面下方。

五、连不上怎么排查（按顺序）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 手机 App 是否已经点了「Start server」？
   没点的话端口根本没开，扫描肯定是 0 个。

2. 手机连的是不是同一个 WiFi？
   手机用流量、电脑连 WiFi，这两个不在一个网里。

3. 路由器/校园网是否开了「AP 隔离」？
   现象：扫描不到，但手动填地址也连不上。
   解决：改用「手机开热点，电脑连热点」。

4. Windows 防火墙弹窗是不是点了「取消」？
   第一次运行时会弹「是否允许 Python 访问网络」，
   必须选「专用网络」并允许。
   改法：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
        找到 python.exe，勾上「专用」。

5. 手机上显示的地址是 127.0.0.1 或 localhost？
   那是手机自己，不能用。要用局域网地址，形如 192.168.x.x
   如果 App 只显示 localhost，说明它没识别到 WiFi，
   先确认手机连上了 WiFi。

6. 地址里的路径对不对？
   IP Webcam 是 /video（不是 /，也不是 /videofeed）
   DroidCam 是 /video，端口 4747
   完整写法：http://192.168.1.7:8080/video

六、几个实际使用要注意的点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

· 手机要插着电。屏幕和摄像头同时工作，半小时就能掉一半电。

· 关掉手机的自动锁屏/省电模式。
  否则录到一半屏幕灭了，App 被系统杀掉，流就断了。

· 无线传输有 0.2~0.5 秒延迟。
  实时识别时，你动作做完，屏幕要慢半拍才反应——
  这是正常的，不是程序卡了。

· 采集数据时帧率会比有线低（一般 10~20 fps）。
  没关系，判定窗口是按「1.5 秒」算的不是按帧数算的，
  帧率低一点不影响特征。

· 如果画面很卡，在手机 App 里把分辨率降到 720p，
  或者把 JPEG 质量调低一档。

· 想确认是「代码问题」还是「网络问题」：
  双击 ⑦ 连不上时，可以用自带的模拟服务器验证程序本身：
      python _test_mjpeg.py --selftest
  它会在本机起一个假手机摄像头并跑完整链路。
  输出「MJPEG 链路可用」= 程序没问题，问题在网络或手机上。
