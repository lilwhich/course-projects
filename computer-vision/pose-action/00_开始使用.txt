====================================================
 人体行为识别（基于骨骼）—— 使用说明
====================================================

这台电脑上已经装好环境，按顺序双击 ①机位自检.bat 就能开始。
换到另一台电脑，见下面「换电脑怎么用」一节。

★ 要做演示？直接看「演示流程.txt」，那份是照着念的稿子。

----------------------------------------------------
 入口顺序（第一次用照这个顺序走一遍）
----------------------------------------------------
⓪一键安装环境.bat   ← 只在【新电脑】上需要跑一次（要联网）
①机位自检.bat       ← 从这里开始，先确认能拍到全身
②采集数据.bat
③训练模型.bat
④实时识别.bat
⑤生成分析报告.bat
⑥导出Excel.bat
⑦手机摄像头.bat     ← 可选：把手机当摄像头（电脑摄像头拍不到腿时用）
环境自检.bat        ← 出问题时先跑这个，会告诉你哪一步不对

----------------------------------------------------
 每个入口干什么
----------------------------------------------------
⓪一键安装环境.bat
    自动创建 .venv 虚拟环境并安装全部依赖（约 500MB，需联网）。
    已经有 .venv 的话会直接跳过。只跑一次。

①机位自检.bat
    打开摄像头，实时画出骨架，并判断能不能拍到全身。
    顶部会给出结论：
      绿色「机位合格」            → 可以采集，往下走
      橙色「看得到膝但看不到脚踝」 → 勉强可用，建议再退半步
      红色「看不到膝盖」          → 必须调整，站/坐无法区分
    屏幕会显示髋、膝、踝三组关键点是否检出，以及人体占画面的高度比。
    键盘：s=保存截图  q=退出
    ★ 这一步不做，后面全白做。

②采集数据.bat
    打开摄像头，实时画出骨架，把每帧骨骼坐标写进 CSV。
    键盘：1=站立  2=坐下  3=行走
          空格=开始/结束一段录制（每段一个文件）
          q=退出
    每类至少录 3 段，建议 4~5 段，每段 15 秒左右。

③训练模型.bat
    用录好的数据训练分类器，打印真实准确率和混淆矩阵。
    混淆矩阵图存到 reports\ 目录。
    ★ 屏幕上那个「平均准确率」是演示时要报的数字。

④实时识别.bat
    摄像头实时判定，画面左上角直接显示「站立/坐下/行走」+ 概率条。
    需要先跑过 ③训练模型.bat。

⑤生成分析报告.bat
    对每段录制出一张三联图（行为时间轴 / 关节角度曲线 / 髋中心轨迹），
    存到 reports\，可以直接贴进课程报告。

⑥导出Excel.bat
    把所有 CSV 汇总成一个 Excel（每段一个工作表 + 一个汇总表）。

⑦手机摄像头.bat
    把手机变成无线摄像头，不用插线。
    自动扫描局域网找手机，也可以手填地址（如 192.168.1.7:8080）。
    配置一次，之后 ①②③④ 全部自动用手机。
    想改回电脑自带摄像头：再跑一次，输入 0。
    ★ 电脑摄像头拍不到腿时，这是最省事的解法。
      手机能放到地上、椅子上仰拍全身，笔记本摄像头做不到。
      详细步骤见「手机摄像头说明.txt」。

环境自检.bat
    打印 Python 版本、各库版本、摄像头可用性、模型和数据是否就位。
    换电脑后第一时间跑它，比瞎猜快。

----------------------------------------------------
 换电脑怎么用（重点）
----------------------------------------------------
1. 把整个文件夹（或那个 zip）拷到新电脑，解压到任意位置。
   路径别放太深，不要有特殊符号，中文路径可以。

2. 装 Python 3.11（如果新电脑没有）：
   https://www.python.org/downloads/
   安装时务必勾选 "Add python.exe to PATH"。
   注意：建议就用 3.11，别的版本部分依赖可能没有现成安装包。

3. 双击 ⓪一键安装环境.bat，等它跑完（3~10 分钟，取决于网速）。
   它会在当前文件夹里建一个 .venv，约 1.4GB，装完就不用再管了。

4. 双击 环境自检.bat，看到「结论：环境正常」就可以开始干活。
   如果报摄像头不可用，先关掉微信/QQ/浏览器的视频占用。

5. 把原来电脑 data\raw 里的 CSV 拷到新电脑同一个位置，
   再跑 ③训练模型.bat，就能接着做，不用重新采数据。

注意：换电脑后不需要重新下载 yolov8n-pose.pt，
      这个权重文件已经放在文件夹里了（6.6MB）。

----------------------------------------------------
 最重要的三条注意事项
----------------------------------------------------
1. 摄像头必须拍到膝盖以下。
   只拍到上半身时，站着和坐着在骨骼上完全一样，
   任何分类器都分不出来——这是物理限制，不是调参能解决的。
   先用 ①机位自检.bat 确认，看到绿色再往下走。

   处理办法，从易到难：
     a) 人退到 1.5~2.5 米，把笔记本放低（垫在矮桌/椅子上），镜头略朝上
     b) 外接 USB 摄像头，摆在大约 1 米高、正对全身
     c) ★用手机当无线摄像头：双击 ⑦手机摄像头.bat
        手机往地上一放、或靠在椅背上仰拍，一定能拍到全身。
        不用插线，配置一次就行。详见「手机摄像头说明.txt」

2. 走路要真的左右横着走。
   正对镜头原地踏步，和站着在骨骼上几乎没区别，会被判成站立。

3. 采集时距离要变。
   至少录一段近距离、一段远距离。
   否则模型学到的是「画面位置」而不是「姿态」，换个距离就失效。

----------------------------------------------------
 目录里都是什么
----------------------------------------------------
config.py           参数设置（窗口时长、模型、类别都在这里改）
features.py         特征工程（归一化 + 关节角度 + 窗口统计）
video_source.py     视频源（本机摄像头 / 手机无线流 / 视频文件）
recorder.py         采集
dataset.py          数据集构建
train.py            训练
realtime.py         实时识别
report.py           离线报告
to_excel.py         导出 Excel
check_camera.py     机位自检
check_env.py        环境自检
setup_phone_cam.py  手机摄像头连接向导
make_demo_data.py   生成合成数据（没摄像头时先看效果用）
viz.py              画骨架和中文文字的小工具
_test_mjpeg.py      模拟手机摄像头的测试服务器（排查网络问题时用）

requirements.txt        依赖清单（宽松版本，一般用不到）
requirements-lock.txt   依赖清单（精确版本，⓪脚本用的是这个）

data\raw\           你录的原始 CSV
data\demo\          合成演示数据（可以删）
models\             训练好的模型（pose_best.pkl 是当前生效的）
reports\            所有图片和 Excel
camera_source.txt   当前用的视频源（0=电脑摄像头，或手机地址）

README.md           完整技术说明（特征怎么设计、踩过什么坑）
演示流程.txt         演示用的流程卡
手机摄像头说明.txt    手机当摄像头的完整说明

----------------------------------------------------
 关于那 1.4GB 的虚拟环境
----------------------------------------------------
.venv 是 Python 依赖（主要是 PyTorch），体积大，所以没有打包进去。
它就在本文件夹下：<解压目录>\.venv

首次使用时双击 ⓪一键安装环境.bat 自动创建，
依赖版本锁定在 requirements-lock.txt 里，不同机器装出来一致。
各功能脚本只认本文件夹里的 .venv，不会去找别处的路径。
